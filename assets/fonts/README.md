- **Instrument Sans** et **Instrument Serif** — SIL Open Font License 1.1.
  Auteurs : Rodrigo Fuenzalida & Jeremy Mickel (Instrument).
  Licence complète : https://openfontlicense.org

Fichiers `.woff2` extraits des sous-ensembles `latin` et `latin-ext`.
Ils sont servis depuis ce dossier : aucune requête vers un CDN tiers,
donc pas de transfert d'adresse IP des visiteurs vers Google (RGPD).

Pour mettre à jour une police, remplacez le `.woff2` correspondant et
vérifiez les `unicode-range` dans `assets/css/fonts.css`.
